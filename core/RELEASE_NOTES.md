# Zapret Studio 2.0 — сборка 18

Первая чистая сборка: только утилита и голые стратегии zapret.

## Что убрано

- **Warframe** — вся настройка, проверка чата, патч стратегии под порты чата, гейм-специфичные тексты. Геймрежим остался: он выключает Game Filter для всех игр и не привязан к конкретной игре.
- **Генокод** — вкладка, ДНК-заставка, недельные замеры, сборка `general (GENO).bat`, файлы `zs-geno.json` и `geno.png`.
- **Авторские стратегии** — `general (TEST1…TEST4).bat`. Осталось 22 чистые стратегии zapret.
- **Telegram-прокси** — кнопка `✈ TG`, панель, локальный SOCKS5, класс `ZTg`, настройка автозапуска. Telegram остался только как сервис в подборе и проверке связи.

## Что добавлено

- **WARP** — кнопка рядом с «Пинг». Режимы WARP / WARP + DoH / только DoH, протокол авто / MASQUE / WireGuard, живой статус с этапами подключения, туториал. Управляет только установленным клиентом Cloudflare через `warp-cli`: ничего не ставит и не перенастраивает.
- **Окно «что нового»** при запуске, перед уведомлением о версии разработчика. Галочка «Не показывать снова».

## Что переписано

- **Подсказки у недоступных настроек** — простым языком и с указанием, куда нажать. Заголовок «🔒 Блокирует:» заменён на «🔒 Недоступно:», причины переформулированы без внутренних терминов.
- **Инструкция** — убраны карточки про Warframe, генокод, Telegram и авторские стратегии; описания приведены в соответствие с чистым составом.
- **Лицензия** — раздел 4 переписан под новый состав, добавлен пункт про WARP.
- **README** — переписан под чистую сборку, добавлен `README.md` для GitHub.

## Техническое

- 7349 строк, ~840 КБ, 0 ошибок парсера PowerShell.
- Удалено около 1000 строк кода и 6 файлов.
- Настройки совместимы: старый `zapret-studio.json` читается, лишние ключи игнорируются.

## Проверка

1. Запустить `ZapretStudio.bat` от администратора.
2. Появится окно «что нового» → «Понял» → уведомление о версии разработчика.
3. Запустить обход, нажать **WARP** рядом с «Пинг» → выбрать режим → «Включить».
